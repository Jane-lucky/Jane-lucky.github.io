## 场景

日常开发中经常需要临时预览静态页面：HTML 演示文稿、前端构建产物、文档站点……不想装 Nginx，不想配 Docker，只想**现在就能访问**。

Python 自带的 `http.server` 模块就是为此而生的——零依赖、一行命令、即起即用。

## 基本用法

```bash
# 进入要服务的目录
cd /path/to/your/site

# 启动服务器（默认端口 8000，默认只监听 127.0.0.1）
python3 -m http.server
```

浏览器打开 `http://localhost:8000`，当前目录下所有文件都可以访问。

## 常用参数

| 参数 | 说明 | 示例 |
|------|------|------|
| `PORT` | 指定端口号 | `python3 -m http.server 3000` |
| `--bind ADDRESS` | 绑定地址 | `--bind 0.0.0.0`（外网可访问） |
| `--directory DIR` | 指定服务目录（不 cd 也能用） | `--directory /tmp/dist` |

### 完整示例

```bash
# 监听所有网卡 + 自定义端口 + 指定目录
python3 -m http.server 8765 --bind 0.0.0.0 --directory /home/user/project/dist
```

## 后台运行

### 方式一：nohup

```bash
nohup python3 -m http.server 8765 --bind 0.0.0.0 > server.log 2>&1 &
echo $!  # 记下 PID，方便后续 kill
```

### 方式二：screen / tmux

```bash
# screen
screen -dmS web python3 -m http.server 8765 --bind 0.0.0.0
screen -r web  # 需要时 attach 回来

# tmux
tmux new-session -d -s web "python3 -m http.server 8765 --bind 0.0.0.0"
tmux attach -t web
```

## 关闭服务器

```bash
# 方式一：按 PID
kill <PID>

# 方式二：按端口
kill $(lsof -ti:8765)

# 方式三：强制
kill -9 $(lsof -ti:8765)
```

## 实战案例：预览 HTML 演示文稿

```bash
# 1. 进入 PPT 目录（含 index.html + assets/）
cd ~/project/wecom-bot-ppt

# 2. 启动服务器
python3 -m http.server 8765 --bind 0.0.0.0

# 3. 浏览器访问
# http://<你的IP>:8765/index.html

# 4. 用完关闭
kill $(lsof -ti:8765)
```

目录结构：

```
wecom-bot-ppt/
├── index.html          ← 主页面
└── assets/
    ├── base.css
    ├── fonts.css
    ├── runtime.js
    └── themes/
        └── corporate-clean.css
```

所有相对路径引用（`assets/base.css` 等）都能正常加载。

## 与其他方案对比

| 方案 | 安装 | 启动 | HTTPS | 适用场景 |
|------|------|------|-------|----------|
| `python3 -m http.server` | ✅ 零安装 | 1 行命令 | ❌ | 临时预览、内网演示 |
| `npx serve` | 需要 Node.js | `npx serve dist` | ❌ | 前端构建产物预览 |
| `php -S localhost:8000` | 需要 PHP | 1 行命令 | ❌ | PHP 项目 |
| Nginx | 需安装配置 | 需写 conf | ✅ | 生产环境、长期服务 |
| Caddy | 需安装 | 自动 HTTPS | ✅ | 快速生产级服务 |

## 安全提醒

> ⚠️ `http.server` 是**开发工具**，不是生产服务器。

- **无 HTTPS**：明文传输，不适合敏感数据
- **无鉴权**：任何人都能访问，`--bind 0.0.0.0` 时尤其注意
- **无缓存控制**：每次都重新读取文件
- **单线程**：并发能力有限
- **目录列表**：默认会列出目录下所有文件

**最佳实践：**

1. 内网演示用 `--bind 127.0.0.1`（默认），只允许本机访问
2. 需要外网访问时用 `--bind 0.0.0.0`，但**用完即关**
3. 生产环境请用 Nginx / Caddy，配合 HTTPS 和访问控制

## 进阶：加上基本鉴权

如果临时需要一点访问控制，可以用这个一行增强版：

```python
# server_auth.py
import http.server
import baseauth

class AuthHandler(http.server.SimpleHTTPRequestHandler):
    def do_AUTHCHECK(self):
        auth = self.headers.get("Authorization")
        if auth != f"Basic {baseauth.encode('user:pass')}":
            self.send_response(401)
            self.send_header("WWW-Authenticate", 'Basic realm="Demo"')
            self.end_headers()
            return False
        return True

# 更简单：直接用环境变量
```

或者更省事——用 SSH 隧道代替公网暴露：

```bash
# 本地启动（只监听 localhost）
python3 -m http.server 8765

# 从另一台机器通过 SSH 隧道访问
ssh -L 8765:localhost:8765 user@your-server

# 然后本地浏览器打开 http://localhost:8765
```

## 总结

| 想要 | 命令 |
|------|------|
| 本地预览 | `python3 -m http.server` |
| 指定端口 | `python3 -m http.server 3000` |
| 外网可访问 | `python3 -m http.server 8765 --bind 0.0.0.0` |
| 后台运行 | `nohup python3 -m http.server 8765 &` |
| 关闭服务 | `kill $(lsof -ti:8765)` |

零配置、零依赖、即起即用——这就是 Python 标准库的魅力。
